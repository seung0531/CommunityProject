CommunityProject

Java 기반의 JSP 커뮤니티 웹 애플리케이션입니다.

사용자가 회원가입 및 로그인을 통해 서비스를 이용하고, 게시글과 댓글을 작성하고 관리할 수 있도록 구현하였습니다. 게시글 검색 및 페이징 기능을 제공하며, 로그인한 사용자는 본인이 작성한 게시글과 댓글을 수정하거나 삭제할 수 있도록 구현하였습니다.

개발 기간

2026.10 ~ 2026.11

사용 기술

Frontend: JSP, HTML, CSS, JavaScript

Backend: Java, Servlet, JDBC

Database: MySQL 8.0

Security: BCrypt, HttpSession

Server: Apache Tomcat 9

Development Tools: Eclipse, MySQL Workbench, Postman, Git, GitHub

기술적으로 해결한 문제

1. 비밀번호 보안 처리

문제

회원가입 시 사용자의 비밀번호를 데이터베이스에 저장할 때 평문으로 저장하면 보안상 위험이 있었습니다.

해결

jBCrypt 라이브러리를 활용하여 비밀번호를 해싱한 후 데이터베이스에 저장하고, 로그인 시 입력한 비밀번호와 저장된 해시값을 비교하도록 구현하였습니다.

2. 로그인 인증 및 접근 권한 관리

문제

로그인하지 않은 사용자가 게시글 작성이나 댓글 작성과 같은 기능에 접근하는 것을 제한해야 했습니다.

해결

HttpSession을 이용하여 로그인 사용자 정보를 관리하고, Servlet에서 세션을 확인하여 로그인 여부에 따라 기능 접근을 제어하도록 구현하였습니다.

3. 게시글 및 댓글 작성자 권한 검증

문제

다른 사용자가 작성한 게시글이나 댓글을 임의로 수정하거나 삭제하지 못하도록 권한 검증이 필요했습니다.

해결

게시글 및 댓글 수정·삭제 요청 시 로그인한 사용자의 ID와 데이터베이스에 저장된 작성자 ID를 비교하여 본인이 작성한 데이터만 수정하거나 삭제할 수 있도록 구현하였습니다.

4. 게시글 검색 및 페이징 처리

문제

게시글이 많아질수록 전체 데이터를 한 번에 조회하면 비효율적이었으며, 검색 결과에서도 페이지 이동 기능이 필요했습니다.

해결

검색 조건에 따라 게시글을 조회하고, 페이지 번호와 페이지 크기를 기준으로 게시글을 나누어 표시하도록 구현하였습니다.
